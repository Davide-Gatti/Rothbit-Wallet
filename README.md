# Rothbit MoonPay sandbox

Servizio riservato alla prova privata testnet, senza chiavi wallet.
Le credenziali MoonPay vanno impostate separatamente nelle variabili Render.
Avvio: npm start. Verifica: npm test.
L’ingresso HTTPS Render fornisce l’IP cliente per la firma del checkout.
Non distribuisce pagamenti live né autenticazione utenti per la produzione.
